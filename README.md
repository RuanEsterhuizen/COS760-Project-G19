# COS760-Project-G19

This is the repository for Group 19's COS760 (NLP) project for 2026 at the University of Pretoria (Department of Computer Science, EBIT)

## Project Details

**Topic:** Detecting Machine Generated Texts

**Objective:** Develop models to distinguish between human- and machine-generated texts in African languages.

## Setup instructions
Follow these steps to run this project for youreself.
### Requirements
* Pyhton 11.9 (this exact version is required, nothing newer).
* Be able to run Jupyter notebooks from your local machine. [Anaconda](https://www.anaconda.com/download) is a popular option for this.

### Cloning the repository
* Run the following command: `git clone https://github.com/RuanEsterhuizen/COS760-Project-G19`

### Training and testing a model
* Open the notebook file (`src/model_training/model_training_setup.ipynb`)
* Uncomment the `model_id` of the model you with to train (remember to comment the others)
* Run all cells

## Project structure
The following section explains the folder structure of the project repository.
```
.
├── README.md
├── data
│   ├── dataset.csv  // the complete, final dataset
│   ├── full_results
│   │   └── // after a training and testing run, detailed results will be saved here
│   ├── hgts
│   │   └── // 3 .csv files of similar size and source composition. Used for generating MGTs
│   ├── mgts
│   │   ├── llama3_1.csv
│   │   ├── mistral.csv
│   │   └── quen2_5.csv
│   └── raw
│       └── // hgt data, as it was pulled from the source datasets
├── doc
│   └── // contains project specifications, project proposal and report
└── src
    ├── data_generating
    │   └── Ollamma_mgt_generator.py    // generate MGTs by prompting a local LLM by using Olamma
    ├── data_processing
    │   ├── AfriHate.py                  // pulls all benign isiZulu entries from the AfriHate dataset and saves
    │   ├── HGT_Subset_Split.py          // creates 3 equally balanced splits from source hgt files
    │   ├── Vukuzenzele.py               // pulls all isiZulu entries from the Vukuzenzele dataset and saves it
    │   ├── combine.py                   // used to combine muliple csv files
    │   └── isiZuluExtract.py            // pulls all isiZulu entries from the Vukuzenzele dataset and saves it
    └── model_training
        └── model_training_setup.ipynb   // classification model training and testing
```
