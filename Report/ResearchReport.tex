    \section{Introduction}
    With the dawn of the 20th decade of the 21st millennium, the arrival of AI models such 
    as ChatGPT has caused rippling effects across the globe, both positive and negative. 
    Such negative effects include the abuse of language models, or "chatbots," to 
    generate text that is difficult to distinguish from human-written content. With 
    further advancements in language models over the years, it has become more challenging 
    for humans to tell whether a piece of text is machine-generated. This research report 
    aims to provide a solution to the problem by using NLP techniques to classify whether 
    a given text is MGT (Machine Generated Text) or HGT (Human Generated Text). The research 
    report details the investigation into creating a Zulu-based MGT detection tool. 
    Zulu/isiZulu was chosen as our primary language since it is the most spoken African 
    language in South Africa and shares linguistic roots with other African languages 
    that fall under the Nguni linguistic tree, which include isiXhosa, siSwati and isiNdebele. 
    Additionally, since isiZulu is not as globally spoken outside of Africa, there is a limited 
    number of models that prioritise generating text in isiZulu. Note that the use of abbreviations 
    MGT (Machine Generated Text) and HGT (Human Generated Text) will be used throughout the 
    research report.

    \section{Literature Review}
    For our study, we consulted previous work performed that also aimed to create a model for 
    MGT detection. The paper "Who Wrote This? Identifying Machine vs Human-Generated Text in 
    Hausa"\citep{hausa} had the aim of developing an MGT detector to identify MGT among HGT 
    written in the Afro-asiatic low-resource language of Hausa, which was achieved by 
    fine-tuning four pre-trained Afri-centric models on a dataset constituting a mixture of 
    News articles in Hausa and MGT that was generated via Gemini. Of the four models, the 
    AfroXLMR model was reported to perform the best. A limitation of the study that was a 
    main point this study wants to address is that the HGT used only consisted of News 
    articles with no consideration of the use of other sources of text. Additionally, the 
    study also only relied on MGT generated by one source without considering other 
    alternative sources. Another consulted paper is "Arabic machine-generated text 
    detection: Stylometric analysis and cross-model evaluation"\citep{alshaibani2026arabic}, 
    which investigated the development of an MGT detector for the high-resource language of Arabic. 
    In the paper, the model was trained on MGT based on formal papers and social media that was 
    generated via various LLMs. When evaluating the model's performance, the researchers found 
    that the model performed worse on MGT based on social media. This was due to how MGT and HGT, 
    when written in a casual context, start to resemble each other. The paper further suggested 
    that to overcome this limitation, the MGT used for training must also be further generalised 
    by changing the prompts used to generate each MGT.

    \subsection{Gathering Datasets}
    The datasets selected to be used to create the HGT dataset include isiZulu News, AfriHate* 
    and Vuk'uzenzele, which are a collection of news articles, social media posts and magazine 
    articles in isiZulu. The datasets were retrieved via the use of Python scripts that extracted 
    the datasets from their respective repositories and then pre-processed to remove irrelevant 
    data and to restructure the format of the dataset so they could be combined later. Further 
    details on pre-processing are covered in the next section.

    \subsection{Pre-processing Datasets}
    After gathering the datasets, each dataset had to be pre-processed in different 
    ways that restructured the datasets and removed irrelevant data. Additionally, 
    another column was added to each dataset labelled "MGT" with all records set to 0, 
    which indicates that the text is human-generated.
     
    \subsubsection{Vuk'uzenzele}
    The Vuk'uzenzele dataset\citep{Vuk'unzenzele} stores the Title of the magazine, 
    the author of the magazine, the text of the magazine article, the edition of the 
    magazine, the language code, which denotes the language that the magazine was 
    written in and the "indexlevel0" column, which is of unknown nature. Since entries 
    in this dataset consisted of entire magazine articles, samples were chunked into 
    individual paragraphs. Bullets and tabs were also removed from the text.
    
    \subsubsection{isiZulu News}
    The isiZulu news dataset\citep{isiZuluNews} stores the ID, the title of the news 
    article, the label of the news article that indicates the type of news article 
    (sports, politics, finances, etc.) and the URL to the news article. The label 
    column was removed since it was not relevant to the task at hand, and the title 
    column was renamed to the source column. Afterwards, the text of the news articles 
    in the dataset was extracted from the provided URL and stored in a new column labelled 
    "text". If the link to the article was not available, then the row with the URL of the 
    missing link is removed from the dataset. Afterwards, the URL column was removed, and 
    the mgt column was then added. The dataset is then stored in a CSV file named 
    "isisZuluDataset.csv".

    \subsubsection{AfriHate*}
    The AfriHate* dataset\citep{Afrihate*} was first cleaned by filtering all text labelled 
    as 'Normal' to ensure all hate speech was removed. Thereafter, the source and MGT columns 
    were appended, where source represents the model that generated the text, and MGT is the 
    Boolean column being filled with '0' for being HGT. Lastly, column names were updated, and 
    columns were reorganised according to our general CSV format, 'id, source, text, MGT', before 
    being saved to their respective CSV file.

    
    \subsection{Creating HGT Dataset}
    After the datasets were pre-processed, each was saved as a CSV file; they were then combined 
    into one CSV file named "dataset.csv" that contains all the HGT via a Python script. Afterwards, 
    the combined HGT set was equally subdivided into 3 CSV files, such that each file contained an 
    equal number of entries.

    \subsection{Generating MGT}
    Ollama was then used to run 3 LLMs locally: Quen2.5, Llama3.1 and Mistral. The 7 billion parameter 
    variations for each of these models were used. For each entry in the HGT source, the corresponding 
    MGT was generated.

    The following system prompt was used for each model:
    \begin{verbatim}
    You are a data transformation model for generating machine text
    Task: Convert the given human-generated text into machine-generated text
    Rules:
    Preserve meaning
    Preserve isiZulu and style
    Do not add explanations
    Output only the transformed text
    Output must be one line long
    \end{verbatim}

    Finally, all HGT and MGT entries were combined into a single file (dataset.csv). The dataset 
    contains 12,969 samples in total and has an approximately equal amount of MGTs and HGTs.
